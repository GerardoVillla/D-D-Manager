# D&D-Manager
![image](https://github.com/GerardoVillla/D-D-Manager/assets/111620583/a0b83068-6ad6-4da8-bbc5-2bd60f4e9994)





En el mundo de los juegos de rol, como Dungeons & Dragons, los directores de juego (Dungeon Masters) a menudo enfrentan desafíos en la gestión manual de personajes, atributos e inventarios, lo que puede ralentizar la experiencia de juego. Nuestra misión es abordar esta problemática desarrollando una herramienta especializada que permita a los directores de juego gestionar personajes de manera eficiente, automatizar procesos repetitivos y mejorar la calidad de las partidas, proporcionando una experiencia más fluida y enriquecedora para los jugadores.

## Requerimientos Funcionales
### Gestión de Personajes
- [ ] R1: El sistema debe permitir a los usuarios crear y personalizar personajes de una partida de Dungeons & Dragons (D&D).
- [ ] R2: Cada personaje debe tener atributos personalizables, como fuerza, destreza, constitución, inteligencia, sabiduría y carisma.
- [ ] R3: Los directores de juego deben poder asignar valores a los atributos de los personajes de acuerdo con las reglas del juego.
- [ ] R4: El sistema debe permitir a los directores de juego asignar nombres, descripciones y trasfondos a los personajes.
  - [ ] R4.1: Los personajes deben estar vinculados al perfil de usuario y se pueden acceder a través de la cuenta del usuario.

### Gestión de Inventarios
- [ ] R5: El sistema debe permitir a los directores de juego crear y gestionar inventarios para los personajes.

### Automatización de Tareas
- [ ] R6: El sistema debe proporcionar herramientas para automatizar tareas comunes, como cálculos de bonificaciones de atributos, lanzamiento de dados y seguimiento de puntos de vida y condiciones.

### Gestión de Datos de Usuario
- [ ] R7: El sistema debe permitir a los usuarios registrarse proporcionando un nombre de usuario y una contraseña segura.
- [ ] R8: Los usuarios deben tener acceso a sus cuentas personales después de iniciar sesión.
- [ ] R9: Los personajes deben estar claramente relacionados con un usuario en particular, de modo que solo el usuario asociado pueda editar o eliminar esos personajes.
